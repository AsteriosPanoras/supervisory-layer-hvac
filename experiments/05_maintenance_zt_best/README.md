# 05 maintenance_zt_best

**Question.** The unchanged layer on ZT Best, the K07 author's later controller (maintenance test), and three registered predictions of the headroom account.

**Where in the paper.** Sections 5.2 and 5.3.

**Outcome.** +5.71 % [3.64, 7.55], all 12 architectures better: the rule held. Predictions: two held, one failed.

**Files here.** PROTOCOL.md, PREDICTIONS_HEADROOM.md, analysis (p250 fidelity, p252), results, execution notes.

**Layout.**
- `PROTOCOL.md`: what was fixed before the runs. Later amendments are separate files, each registered before any outcome.
- `analysis/`: the analysis scripts, hashed before the runs they read.
- `results/`: their outputs.
- `execution/`: job lists and launch scripts.
- `EXECUTION_NOTES.md`: events during the runs, recorded as they happened.
