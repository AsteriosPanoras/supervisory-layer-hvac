# Experiments

Every experiment was registered before its outcome existed: its protocol, its analysis script and the hashes of both went into the ledger (`integrity/`). A rule or prediction that failed is reported as failed. The blind set was never used to design or select anything.

| [`02_development_gates`](02_development_gates/) | Development gates of the learning source: each mechanism had to gain on the composite development architectures with no architecture more than 1 % worse | Appendix H | Learned start and pressure reset passed on K07; the start failed on Penguin, learned night precooling passed. |

**Arms and keys.** Each job line is `building weather policy_key steps`. The policy key names the controller and its settings, for example `k07sup@<G30 constants>;ROS=1,TR=1` = K07-G30 with the learned start (ROS) and the pressure reset (TR). Each experiment's manifest maps the keys to arm names.
