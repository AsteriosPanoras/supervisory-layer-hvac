# H2 pre-registration v1 — DRAFT

## Question
Does a one-time M-gate (read the observed class at step 228; observed M -> daily re-selection rule PD5 for the whole episode, otherwise select-once rule PS5) beat the sparse-persistence rule TRIG2 on weather and buildings no earlier experiment used?  The gate was DISCOVERED on the inspected H0 data (retrospective Mgate-TRIG2 +0.42 points [0.17, 0.75] on 88 cells); H2 is its prospective test.  No learned component.
## Data
- Weather: NOAA full ISD 2021, 42 stations (the 30 project stations + 12 of the H0-S stations; birmingham dropped: raw file unusable), parser noaa_year.py (validated on 2023: Boston temperature MAE 0.004 C).  No earlier experiment used a start date in 2021 (all cross/scenario tables: 2023 and 2022 only).  Exact-window QC (Rule W) on the raw file for every candidate window; 720 h; no two windows of one station closer than 35 days; at most 3 windows per station.
- Cells (cells_h2.csv, make_design_h2.py): 100 MAIN (C 30 / M 44 / H 26, quotas follow the reference weights) + 20 EXTENSION cells (C 6 / M 9 / H 5) in a fixed order, used only if throughput allows, never chosen by outcome.  Half of every class on GEN12 buildings (seen in H0 under 2022 weather: isolates the weather shift) and half on GEN14 (60 new variants, same six parent families: variant-stress subset).  Crossed design: GEN12 buildings are reused (36 buildings for 50 cells).
- Arms (h2_arms.json), all REAL runs, 8640 steps: B, PS5, PD5, TRIG2, G30 (frozen g2_014), MG (runner run_episode_k07_v8_mg.py, mode k07unif@mgatehot).  Every cell is a matched bundle on ONE machine.
## Hypotheses
PRIMARY: MG minus TRIG2, points of B-referenced gain, equal-cell weights, 95 % station-cluster bootstrap (3000, seed 1) over the 100 main cells (p128_h2_analysis.py main).  Support if the interval excludes 0 and the point estimate > 0.  SECONDARY (no multiplicity claim): MG-PD5, MG-PS5, MG-G30, PD5-PS5, class-weighted version, by class, by generator subset (GEN12 vs GEN14) with the difference between subsets, harmed >1 % share, worst cell, realised switches.  Extension cells pooled only as 'extension'.
## QA gates (all before the main queue)
1. Data parity byte for byte (GEN12/GEN13/GEN14 and 2021/2022 weather) on source, laptop, host-B, Kaggle dataset.  2. Runner v8 sentinel: MG on 6 H0 cells (2 each C/M/H) on all 3 machines must equal the existing PD5 (M) or PS5 (non-M) results (exact on host-B/laptop, within the Kaggle tolerance 0.5 %), with mgate_flag == (observed class at step 228 == M).  3. Machine spread in the sentinel <= 2 %.  4. No H2 cell is run before these pass; any failure -> NO-GO for the affected machine.
## Stopping / reduction rules (fixed now)
Main queue first, extension afterwards; if the projected end exceeds the buffer (15-20 %), extension cells are dropped from the END of the fixed order; incomplete bundles are excluded from all comparisons and reported.  No policy, metric or primary comparison changes after the first H2 run.
## Limits
Simulator only; 42 stations, one new year, six parent families; nominal intervals; M-gate discovered retrospectively so shrinkage is expected; H0-Y2 stays exploratory and is not used to choose anything here.

The scheduler version frozen at 02:59 re-ran a whole chunk when any of its jobs had no result, which would have wasted compute and could have stopped a machine after three failures.  Amendment: (1) only jobs WITHOUT a result are re-queued, once; a job without a result after its second attempt is a PERMANENT FAILURE, listed in PERMANENT_FAILURES_h2r.txt; (2) results of episodes that did finish are always kept; (3) the scheduler was restarted at 03:56:54 with prefix h2r (previous chunks h2p01, h2p02, h2k01 keep their valid results; the duplicate re-runs h2p03 (killed) and h2k02 (Kaggle, cannot be cancelled) are ignored; laptop chunk h2l01 is adopted); (4) the deadline of the extension rule keeps its original wall-clock value (11:29:33 = start of the main queue + 8.5 h).  Pre-declared consequences (rule of the H0 pre-registration and of this document): a building that the simulator cannot initialise is excluded for ALL arms of ALL its cells; incomplete bundles are dropped from every comparison and listed; NO replacement cells are added; the number of complete main cells, the GEN12/GEN14 split after exclusions and the excluded buildings are reported with the result.  The exclusions follow from the simulator defect, not from any outcome.
