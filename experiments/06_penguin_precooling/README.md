# 06 penguin_precooling

**Question.** Learning retargeted to energy: learned night precooling on Penguin (development gate, then blind).

**Where in the paper.** Section 5.2.

**Outcome.** +1.88 % [1.12, 3.07], all 12 architectures better.

**Files here.** PROTOCOL.md (gate), analysis (p239 fidelity, p240 gate), results; blind contrast in analyses/p281.

**Layout.**
- `PROTOCOL.md`: what was fixed before the runs. Later amendments are separate files, each registered before any outcome.
- `analysis/`: the analysis scripts, hashed before the runs they read.
- `results/`: their outputs.
- `execution/`: job lists and launch scripts.
- `EXECUTION_NOTES.md`: events during the runs, recorded as they happened.
