# K07-X3: fresh blind test set (built 2026-11-10, outcome-blind, nothing uploaded)

12 never-used architectures from the OFFICIAL floor generator (10 composite + 2 OOD), each with 3 never-used weather strips (one COLD, one MILD, one HOT day-1 class) = **36 scenes**,
generated by the OFFICIAL scenario generator in a private kit copy, smoke-tested with K07 (120 steps) through the laptop stage mechanism, packed for Kaggle, the laptop and host-B.
No simulation result influenced any choice: the smoke runs came after the cohort was fixed, and no score was read.

## Architectures
* **Composite (10):** one official batch, seeds 52200-52219 (materials stratified across the batch by the official `draw_materials`, rng from sha256(repr(seeds)) exactly as K07-X),
  `build_config` with `DEFAULT_RANGES` (composite / architectural). The 10 = the first 10 seeds that pass the official 20 m2 zone-area acceptance check
  (the scenario generator's own `_check_generated_zone_areas` on the seeded plan). **Rejected (re-seeded by taking the next seed): 52202 (3 zones, smallest 12.16 m2), 52204 (3.64 m2), 52210 (7.20 m2).**
  Accepted: 52200, 52201, 52203, 52205, 52206, 52207, 52208, 52209, 52211, 52212; 52213-52219 drawn but unused (reserves).
* **OOD (2):** the generator has no non-composite shape that K07-X never drew (v1 drew all 10). The 2 OOD = 2 of the 5 shapes NOT in the K07-X v2 cohort (rectangle, pentagon, u_shape,
  parallelogram, triangle) with the smallest sha256('K07X3|OOD|shape|<shape>'): **triangle (52300), parallelogram (52301)**, new seeds, official stratification over the batch of 2; both pass.
* Zones 23-105, AHUs 3-11 (table in `K07X3_MANIFEST.md`). Seeds 52200-52219 / 52300-52301 appear nowhere else (K07-X kit, local kit, scenario indexes checked).

## Weather (DEVIATION from the brief)
**What the kit offers:** 6 recorded stations (`weather/csv/`: atlanta, denver, fairbanks, minneapolis, phoenix, singapore; 2023 hourly, 8760 rows) and 48 official strip presets
(`weather/<station>_1..8.yaml`: 30-day windows, start Sunday 06:00 every 6 weeks, one convection coefficient per station). Nothing else (one 10-row simulator test file, Mountain View, is not a strip).
All 48 are used (30 by the shipped training set, 10 by K07-X development, minneapolis by K07-X held-out), so **no official station outside atlanta/denver/fairbanks/phoenix/singapore/minneapolis exists.**
Fresh windows of those six do not exist either: the project's recorded crossed windows cover every day of 2023 for denver, fairbanks, minneapolis and phoenix (atlanta 5 free days, singapore 19).

**What was done:** 36 NEW strips **built the official way** (a 30-day window of recorded hourly station data, start 06:00, official yaml preset, the station-year convection coefficient the project's
design files record) from the project's **NOAA station bank** (`N9_design/laptop_run/scen/weather`, the official csv format), **year 2022** (the least-used year), 28 stations, none of the six.
* Candidates: every Sunday 06:00 start of 2022 (window ending by 31 Dec) whose 31 days overlap **no** window recorded in any of the 94 design files with station+start columns (8458 windows,
  each counted as 30 days); checked again afterwards: no overlap with any `<station>22_wMMDD` name in any of 194 csv files that carry a weather column.
* Day-1 class: T19 = mean outside-air temperature of steps 0..227, computed **without simulation** by `k07x3_t19.py` (the kit's own ReplayWeatherController; the simulator reads the naive start
  as UTC) and validated against the 18 K07-X probe values (max error 0.005 K). Margin >= 1 K from every threshold: C in [-14, 10] C, M in [12, 23.5] C, H >= 25.5 C (none borderline, none class E).
* Pools (outcome-blind hash rule, k07x_v2_cohort.py style): per class (H, then C, then M) candidates in the order sha256('K07X3|STRIP|<class>|<station-year>|<start>'), taken greedily with distinct stations
  inside a class and no two chosen windows overlapping on one station-year: 12 per class, **no strip shared**. Architectures in the order sha256('K07X3|ORDER|<name>'); architecture i gets C[i], M[i+a],
  H[i+b] with the smallest offsets giving three different stations: a = b = 0 works.
* H was not scarce (292 H candidates in margin). HOT strips T19 25.55-32.74 C (newyork22/boston22 0821 are the mildest at 25.55); COLD -5.97 to 8.24 C; MILD 14.97-22.74 C.
* **Honest limit:** the stations themselves were used by earlier project experiments in other years/windows (2021 H2/D/M2 cohorts, 2023 crossed windows), so the set is new in buildings, in weather
  days and in stations relative to K07-X, not in climates relative to the whole project. The data are NOAA recordings prepared by the project, not files shipped with the kit.
* **Official-only fallback (not built):** the 30 shipped training strips are official and unused by K07-X (H 12, C 9, M 8, E 1; `OFFICIAL_TRAINING_STRIPS_DAY1_CLASS.json`), but they are in the excluded
  stations and are the competition's training weather. Rebuilding the 36 folders from the same building yamls takes about 5 minutes with `k07x3_cohort.py`-style generation.

## Smoke test
Key `k07@RAMP=0.25,COLD_SAT=-0.8,HEAT_U_SCALE=0.875,KP=0.075,NIGHT_HEAT_DROP_K=3,MILD_SHIFT_K=0.75`, 120 steps, every building on its HOT strip, through
`run_stage_laptop_k07x3.sh K07X3_SMOKE 2 k07x3smoke run_episode_k07_v9x.py 12-13` (kernel_runner_v3 KRE-v2 with the PR #1 overlay check, trk_kit as the competition root),
2 workers, nice 19, cores 12-13. Experiment folder: `N9_design/laptop_run_k07x2/exp/K07X3_SMOKE/jobs/stage1.jobs`; outputs in `laptop_run_k07x3/work_k07x3smoke/`.
**Result: 12/12 OK, 120/120 steps each, 0 illegal actions.** Peak RSS 985-1434 MB, except **building_52207 2363 MB** (4 floors, 634x499 ft); episode wall (summary) 26-120 s, runner wall with start-up 67-222 s; the stage took 654 s with 2 workers. No score was read. Per-building values: `K07X3_MANIFEST.md`.

* **host-B (experimenter copies; base `<host-b>/`):**
  1. `<N>/k07x3/kaggle_k07x3_scen/` (contents, 346 MB) -> `sb_work/k07x3/scen/` (a real folder)
  2. `<N>/k07x3/run_stage_host-B_k07x3.sh` -> next to `run_stage_host-B_k07x2.sh`
  3. on host-B: `ln -s ../k07x2/exp sb_work/k07x3/exp` and `ln -s ../k07x2/trk_kit sb_work/k07x3/trk_kit`
  4. each K07-X3 experiment folder, e.g. `N9_design/laptop_run_k07x2/exp/K07X3_SMOKE/` -> `sb_work/k07x2/exp/K07X3_SMOKE/`; run `run_stage_host-B_k07x3.sh <EXPERIMENT> stage1 <WORKERS> <NAME>`
  Do not merge the scenes into `sb_work/k07x2/scen`: that would need an edit of its scenarios.csv.

## Run time
See `K07X3_MANIFEST.md` (last column and the run-time paragraph) and `K07X3_SMOKE_AND_RUNTIME.json`.
10-day run = r x smoke wall with r = 7.63 (range 5.98-9.28 from the two references measured the same way: building_52007 smoke 180.7 s -> 18 min, building_52105 168.1 s -> 26 min); 30-day = 3x. **Per scene, one local worker: 10-day 3-15 min (central; building_52207 15 min, 52205 3 min, the others 5-8 min), 30-day 10-46 min.** All 36 scenes x one policy key: about 4.3 h (10-day) / 12.9 h (30-day) of single-worker time; a zones-only cross-check gives 4.5 h (10-day). Memory: plan 1.5 GB per run, 2.4 GB for building_52207.
